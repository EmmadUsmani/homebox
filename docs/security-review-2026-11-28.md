# Mac isolation review · 2026-11-28

Scope covers a macOS host, an Ubuntu guest with root access, and the CLI and
desktop clients that consume guest data. Severity describes the potential
effect of the gap. Unit tests and development-VM checks exercise configured
boundaries. A guest that controls its SSH server can falsify its own doctor
or status results, so a passing report cannot attest to a guest's integrity.

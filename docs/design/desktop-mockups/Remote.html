Host key changed: not connecting
The VM answered with a different key from the one pinned when it was set up. Either it was rebuilt, or something else is answering in its place. homebox won't connect until you've checked.
If you rebuilt it on purpose: on that Mac run box repin work, then reinstall the laptop SSH config.

Other states the app can show for a VM on another Mac

Unreachable
The name doesn't resolve or the connection timed out.
Likely: The Mac is off, asleep or not on this network.
VM not running
The Mac answered but refused the connection.
Likely: box's SSH relay only listens while the VM runs, so the VM is probably stopped.
Connection broken
TCP connected but the SSH handshake failed.
Likely: sshd in the VM is down or still booting.
Reachable
Logged in with the pinned key.
Likely: Status, logs, terminal and files work as for a VM on this Mac.
These are hints, not diagnoses. The app can't start, stop or create VMs on another Mac, and can't tell a stopped VM from a deleted one.

# Linux isolation review · 2026-11-28

Scope includes the x86-64 Ubuntu 26.04 host with Linux 7.0, Lima 2.3.0,
QEMU/KVM, the host gateway and the CLI and desktop paths that consume guest
data. The confinement probes use installed rules and local canaries.
Guest-side checks assume an honest SSH endpoint and a known test image.

| Control | Automated check | Gap, severity and status |
|---|---|---|
| QEMU launch contract | [Launch and live argument tests](../internal/confine/profile_linux_test.go), [doctor](../internal/doctor/ssh_relay_linux.go), [VM test](../e2e/box_test.go) | Doctor checks the exact restricted SLIRP entry and a live connected Unix stream descriptor for the separate gateway. The launcher verifies the configured Unix peer before exec. Repeat on Lima upgrades. |
| SLIRP IPv4 TCP, UDP and ICMP | [Guest doctor](../guest/common/doctor.sh), [host canaries](../internal/doctor/host.go), [VM test](../e2e/box_test.go) | Host-side TCP and UDP canary replies establish that listeners are available. | Landlock reads, writes and exec | [Doctor confinement canaries](../internal/confine/probe_linux.go) for hostagent, QEMU and gateway | Moderate, tightened. The library tree had blanket exec permission and also contains executables. The profiles now allow library reads and the required ELF loader, alongside each profile's explicit program paths. The hostagent trusts its Lima runtime and shared config. The probe exercises one denied home read, write and direct exec per profile. Direct exec checks do not prevent a compromised process from running code within its own address space. |
| Signals, procfs and process inspection | [Doctor confinement canaries](../internal/confine/probe_linux.go), [kernel filter test](../internal/confine/seccomp_linux_test.go) | Defense in depth added. Doctor checks signal and procfs reads against its unconfined parent. All three profiles now deny ptrace and cross-process memory syscalls. The test does not enumerate every procfs entry or every pairing of live helpers. A minimum-ABI host run remains open. |
| Socket families, io_uring and alternate send paths | [Kernel filter test](../internal/confine/seccomp_linux_test.go), [doctor confinement canaries](../internal/confine/probe_linux.go) | Doctor checks abstract Unix denial, pathname Unix denial for QEMU, and the distinct TCP, datagram, netlink and send policies. Hostagent TCP permission is port-based. Hostagent and gateway can reach pathname Unix sockets. Gateway IPv4 egress filtering depends on gateway code. These are residual limits after compromise of a host helper. |
| Inbound SSH ownership | [Pidfd peer regression](../internal/vmnet/ssh_socket_linux_test.go), [doctor](../internal/doctor/ssh_relay_linux.go) | Doctor now checks the same recorded pidfd identity as the published relay. The driver TCP endpoint is checked separately. The local fixture covers another live PID owning the endpoint. |
| Guest status, top and logs | [Bounded status](../internal/app/status_test.go), [journal parsing and retention](../internal/app/logs_test.go), [text sanitizer](../internal/untrusted/text_test.go) | Guest telemetry is advisory. Host resource samples use Linux procfs with PID/start-time and command-line checks. The guest's procfs is read in the guest and its output is parsed with host-side size, numeric and display limits. |
| Native desktop viewer | [GTK isolation fixture](../desktop/scripts/verify-desktop-isolation-linux.js), [proxy tests](../internal/displayproxy/proxy_test.go), [documented viewer limits](../SECURITY.md#linux-guest-viewer) | Existing coverage for separation from Wails bindings, navigation, standard clipboard, and ephemeral state. | Gateway flows, logs and disk | [Flow limits](../internal/vmnet/flows_test.go), [daemon log rotation](../internal/egress/daemon_log_test.go), [disk resize](../e2e/resize_test.go) | Per-VM flow limits, gateway log rotation and per-disk virtual capacity have checks.

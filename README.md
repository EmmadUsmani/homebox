# homebox

An exe.dev-style development VM on your own hardware. Run homebox on a Mac,
Windows or Linux machine, then SSH from your laptop straight into an isolated
Linux VM. In the VM you can run coding agents such as Claude Code and Codex with
full permissions, run any server, and render and screenshot UI.

**Status:** design only. Nothing is built yet.
